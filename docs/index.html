what it does

  • Keeps a list of servers, grouped and with optional jump hosts.
  • Shows status and live metrics: CPU, memory, load, uptime, disks, network.
  • Lists processes, sorts them and sends SIGTERM after a confirmation.
  • Opens an SSH shell, or runs saved commands on a server.
  • Runs one-shot checks from scripts: scat --check web1.

principles

  • Keys only. scat never asks for or stores passwords. Monitoring uses ssh -o BatchMode=yes.
  • Plain config. Files are parsed as data, never evaluated, and written with mode 600.
  • Plain Bash. No runtime dependencies beyond Bash 5 and tools that ship with macOS.

install

Requires macOS and Bash 5 from Homebrew. The system /bin/bash is 3.2 and is not supported.

$ brew install bash
$ curl -fsSL https://raw.githubusercontent.com/d3m0naz/scat/main/install.sh | bash
$ scat --help

The installer checks the SHA-256 of the release archive before it installs anything. To install elsewhere, set SCAT_PREFIX. Releases and checksums are on the releases page.

remote hosts

Remote hosts need a POSIX sh with awk, ps and df. Linux and FreeBSD (including OPNsense) give full metrics. macOS hosts work on a best-effort basis.
