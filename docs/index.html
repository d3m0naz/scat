install scat

$ curl -fsSL https://raw.githubusercontent.com/d3m0naz/scat/main/install.sh | bash
$ scat --help

The installer runs with the first bash in PATH, so Bash 5 is needed first, see the next section. It checks the SHA-256 of the release archive before it installs anything, puts scat into ~/.local/share/scat-<version> and links ~/.local/bin/scat. If ~/.local/bin is not on your PATH, add it: export PATH="$HOME/.local/bin:$PATH". To install elsewhere, set SCAT_PREFIX. Releases and checksums are on the releases page.

bash 5 or newer

scat is a Bash script that runs on the machine you work on. It is written for any system with Bash 5 or newer and the usual Unix tools. So far it has been run on macOS (Apple Silicon); Linux and FreeBSD as the machine running scat have not been tested yet. Check your version with bash --version.

what it does

  • Keeps a list of servers: add, edit, delete and reorder, with group headings and optional jump hosts.
  • Shows status and live metrics: CPU, memory, load, uptime, disks, network per interface.
  • Scrolls the detail view when it is taller than the screen, with a position indicator.
  • Lists processes, sorts them and sends SIGTERM after a confirmation.
  • Opens an SSH shell, or runs saved commands on a server.
  • Runs one-shot checks from scripts: scat --check web1.

principles

  • Keys only. scat never asks for or stores passwords. Monitoring uses ssh -o BatchMode=yes.
  • Plain config. Files are parsed as data, never evaluated, and written with mode 600.
  • Plain Bash. No runtime dependencies beyond Bash 5 and standard Unix tools: ssh, tput, stty, awk, sed, sort, mktemp, grep, pkill.

The terminal needs at least 80×24. In a smaller window scat shows a short notice until the window is large enough again.

remote hosts

Your servers do not need Bash: scat only needs SSH access and a POSIX sh with awk, ps and df there. Tested live: Linux (Debian 13, arm64) and FreeBSD 15 (OPNsense), both with full metrics. macOS hosts work on a best-effort basis.
